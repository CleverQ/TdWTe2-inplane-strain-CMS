# First-principles calculation inputs

This directory contains the lightweight production inputs and relaxed structures for the unstrained state and ten tensile-strain states (`a` and `b`, +0.1% to +0.5%). Each state contains `POSCAR`, `CONTCAR`, `INCAR`, and `KPOINTS`.

`POTCAR`, `WAVECAR`, `CHGCAR`, large `OUTCAR` files, and other regenerable intermediates are intentionally excluded.
